# RideLog Android source
A standalone private journey timer, not a ticketing app. No ticket creation, validation, purchase, or SBB branding.

Features: swipe Start, stopwatch, end/save trips, searchable Swiss station list, editable profile name, local history, offline storage.

## Build the APK
Open this folder in Android Studio, allow Gradle sync, then choose **Build > Build APK(s)**. APK output is normally `app/build/outputs/apk/debug/app-debug.apk`.
This environment has no Android SDK or Gradle installation, so an APK was not compiled here. The complete source project and HTML preview are included.
